Como criar um modelo de contrato

Prepare seu arquivo Word, marque os campos que serão preenchidos automaticamente e cadastre o documento na biblioteca do Campanella.

5 etapasModelos .docxPara administradores
01

Prepare o arquivo no Word

Escreva o contrato com as cláusulas e a formatação que deseja utilizar. Salve como Documento do Word (.docx).

✓ O limite por arquivo é de 2 MB.
✓ Você pode usar títulos, parágrafos e tabelas.
✓ Use marcadores nos pontos onde deseja que o sistema insira informações.
02
CAMPOS DINÂMICOS

Você escolhe quais informações o contrato vai pedir

Não existe uma lista fechada: você pode criar um campo para qualquer informação, como RG, profissão, material didático ou objetivo do curso. Basta escrever o marcador no Word seguindo esta fórmula:

FÓRMULA PARA USAR NO WORDObrigatória
<<nome_campo/quem_preenche>>
nome_campoQual informação deseja coletar? Você inventa o nome.
/A barra separa o nome de quem vai preencher.
quem_preencheEscolha exatamente contratante ou contratado.

Quem deve preencher o campo?

contratante

Aluno ou responsável

O campo aparece para a pessoa preencher pelo link de assinatura.

contratado

Escola / administração

O campo é preenchido pela escola antes do contrato ser enviado.

EXPERIMENTE AQUI

Monte seu próprio campo

Escreva o nome que quiser, escolha quem preenche e copie o resultado para o seu documento Word.

Interativo
Ex.: objetivo_curso · Sem espaços ou acentos
Esta escolha define quem verá o campo.
SEU MARCADOR PRONTO PARA COLAR<<objetivo_curso/contratante>>

Pronto! Coloque esse texto no local desejado dentro do seu contrato Word.

Exemplos de ideias para campos

São apenas sugestões. Você pode criar outros nomes e escolher qualquer um dos dois responsáveis pelo preenchimento.

<<rg/contratante>><<profissao/contratante>><<livro_utilizado/contratado>><<objetivo_curso/contratante>>
Para o marcador funcionar

Use letras minúsculas, números e underline (_), sem espaços ou acentos. O nome deve começar com uma letra e ter de 2 a 40 caracteres. Mantenha <<, / e >>. O termo assinatura é reservado para os marcadores da próxima etapa.

Se repetir a mesma informação em vários trechos do Word, use o mesmo marcador e o mesmo responsável em todos eles.

Campos que o Campanella já reconhece

Você também pode aproveitar estes campos automáticos, que vêm de informações do cadastro e da ficha inicial.

<<aluno_nome/contratante>><<contratante_nome/contratante>><<curso/contratado>><<valor_total/contratado>><<data_inicio/contratado>><<data_fim/contratado>><<grade_horarios/contratado>><<qtd_aulas/contratado>>
03

Posicione as duas assinaturas

Em vez de deixar apenas uma linha em branco, insira os marcadores abaixo no lugar exato em que deseja cada assinatura.

<<assinatura/contratante>>
CONTRATANTEAssinatura feita pelo link
<<assinatura/contratado>>
CONTRATADAAssinatura cadastrada pela escola
Importante

Esses dois marcadores são obrigatórios nos novos modelos. O sistema utiliza a assinatura da escola cadastrada em Configurações e a assinatura feita pelo aluno no link. O modelo de dupla ainda não tem assinatura pública de dois contratantes nesta versão.

04

Cadastre na biblioteca

1

Abra Modelos de contratos no menu lateral e clique em Novo modelo.

2

Informe o nome, selecione a modalidade e envie o arquivo .docx.

3

Se desejar, marque os pacotes que usarão esse modelo como padrão.

4

Salve. O modelo ficará disponível ao gerar novos contratos.

Se um pacote não tiver modelo associado, será possível escolher um modelo manualmente na matrícula. O cadastro de pacotes é opcional para matrículas personalizadas.

05

Faça uma conferência antes de usar

Após salvar, clique em Visualizar para conferir o texto e a identificação dos campos. Em seguida, crie um contrato fictício, abra o link e veja como o documento fica para o aluno.

✓ Os dados pessoais aparecem nos campos certos?
✓ Os dias e horários correspondem à ficha inicial?
✓ As assinaturas aparecem onde foram marcadas?
✓ O modelo correto foi selecionado para o pacote?
Preservação do histórico

Alterações no modelo são aplicadas a contratos novos. Os contratos já criados guardam uma cópia própria e não devem mudar retroativamente.

Dúvidas comuns

Posso usar o mesmo modelo em mais de um pacote?

Sim. O mesmo modelo pode ser vinculado a vários pacotes. Cada pacote tem um modelo padrão por vez.

O aluno recebe um arquivo Word depois de assinar?

A via assinada disponibilizada pelo link é em HTML e pode ser salva em PDF pelo navegador. O DOCX gerado antes da assinatura não incorpora a imagem desenhada pelo aluno.

O que acontece se eu desativar um modelo?

Ele deixa de estar disponível para novos contratos. Isso não altera os contratos já criados.

Preciso cadastrar uma assinatura padrão?

Não há imagem de assinatura predefinida no projeto. A escola deve cadastrar sua assinatura na área Configurações.
